# Fairino 连续手眼标定

采集器复用 WVCSC 的单池采集语义：根位姿先经过完整图像、PnP、TF 和
静止门控并记录为第 1 个样本；随后依次执行 19 个固定相对 SE(3) 动作。
所有目标由 `base_T_root * root_T_tool_delta` 单独计算，MoveIt 从当前实际状态
直接规划到下一个目标，不在动作之间回根位姿。

固定安装和标定码不变；根位姿为 `(0.3150, 0.0325, 0.3506)` m、
`(0°, 180°, 90°)`。结合当前 `grasp_frame -> camera_color_optical_frame`
安装真值，该姿态把相机光心放在标定码中心正上方约 `0.400 m`。根样本采用正对
视角保证居中和恢复余量，后续 19 个动作再提供多轴斜视激励。动作在 YAML 中
配置，`collector/config.py` 保存相同后备值；显式 ROS 参数、YAML 和 Python
后备值依次覆盖。动作表采用两位小数，同时激励三维平移和三个旋转轴；改变根位姿
或标定码位置后须重新执行 MoveIt 与可见性预检。

每一个端点都必须通过 10/10 连续图像、距离、边缘、像素尺寸、PnP、IPPE、
精确图像时间戳 TF、机器人静止和样本去重门控。规划失败停在当前安全点；已到位
但视觉或样本门控失败时只恢复一次最后安全点，然后继续下一个绝对 root-relative
目标。会话结束时才返回根位姿一次。

**分步模式**：`step_between_actions`（默认 true）开启时，每个标定动作执行前
需在 CLI 按 Enter 才继续（q 可中断）。非交互运行（launch/管道等无 TTY）自动
连续执行，不会卡死。

固定标定码仿真允许 10/10 稳定帧中的 IPPE 最优解保持双解；它仍必须通过 PnP
重投影、时间戳 TF、姿态静止和最终求解门控。实机如出现双解不稳定，可将
`ippe_min_non_ambiguous_frames` 提高为正数。

20 个候选全部尝试。至少接受 15 个样本才进入求解；求解前要求至少 20 组
`17°～120°` 相对旋转，且旋转轴散布矩阵的 `λ2/λ1 ≥ 0.20`。Park 和 Horaud
必须同时成功且差异小于 `3 mm / 1°`。Tsai-Lenz 只输出诊断；当前严格
`Rz(180°)` 相机安装会标记为 `not_applicable_half_turn`，不参与结果否决。
只有固定标定码残差失败允许删除最差样本，且绝不低于 14 个；可观测性、算法
一致性、安装关系和仿真真值失败直接拒绝结果。输出仅有同一时间戳的 `.calib` 和
`.samples`；未达数量或质量门控时仅保存标有拒绝原因的 `.samples`。

仿真额外比较 `grasp_frame -> camera_color_optical_frame` 的实时 TF 真值，要求
平移小于 3 mm、旋转小于 1°。实机不具有该真值门控，仍使用相同的图像和
固定标定码质量门控。
